# 日次レポート作成スキル

以下の手順で日次レポートを作成してください。

1. `git log --since=yesterday --oneline` で昨日からのコミットを確認する
2. `reports/` フォルダの直近の実行履歴を確認する
3. 以下の形式で日本語のレポートを作成する:

```
## 日次レポート（{今日の日付}）

### 進捗
- （コミットやタスクの要約）

### 気になる点
- （エラー・失敗・停滞があれば）

### 今日やるべきこと
- （提案）
```

レポート本文をそのまま出力してください（ファイル保存は不要です。
スケジューラーが自動で reports/ に保存します）。
